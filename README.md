# 🧮 Calculator

A simple and responsive calculator application built using **HTML, CSS, and JavaScript**.

## 🚀 Features
- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Percentage (%)
- Power (^)
- Decimal calculations
- Brackets support
- Clear (C) and Delete (DEL) buttons
- Keyboard support
- Responsive and attractive user interface

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📸 Project Preview
Open `index.html` in your browser to use the calculator.

## 💻 How to Run
1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start calculating!

## 🎯 Purpose
This project was created to practice HTML, CSS, and JavaScript and understand DOM manipulation and event handling.
